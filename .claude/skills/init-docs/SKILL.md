# init-docs · 手动初始化文档体系（自举兜底）

> **为什么需要它**：正常情况下，AI 首次进项目会读到 `AGENTS.md` 顶部的「🚧 AI-INIT」一节并自动初始化。本 skill 是它没被执行时的显式入口，把「自动自举」变成「一条命令可触发」。
>
> **唯一权威流程是 `AGENTS.md` 顶部的 AI-INIT 一节**，本 skill 不另写一份步骤——两处各写一份，迟早会改了一处忘了另一处。

## 执行步骤

1. **先判定是否真未初始化**：`grep -n 'AI-INIT-STAR[T]' AGENTS.md`（`[T]` 让这条命令写在文档里也不会匹配到自己）。
   - 无输出 → 已初始化：停止，告诉用户「无需初始化」。若 `sh check-docs.sh` 报了个别占位符残留，只修那几处，不要重跑初始化。
   - 有输出 → 继续。
2. **用 Read 读 `AGENTS.md` 原文**（Claude Code 自动加载的版本会剥掉 HTML 注释），按顶部 AI-INIT 一节逐步执行：问清信息 → 扫仓库生成骨架 → 清理与自检 → 最后删除该节。脚手架已由 `init.sh` 按项目类型生成（类型见根目录 `.vibe-template`），不要删改。
3. **收尾**：跑 `sh check-docs.sh` 确认通过；向用户简述生成了哪些骨架、哪些表待随开发补全，然后继续用户的原始请求。

## 注意

- 没有真实值的占位符：删掉该行 / 该节，或写「（暂无，随开发补充）」，不编造。
- 密钥 / 内网地址不写进任何入库文档，用占位符。
- 初始化只碰文档，不擅自改脚手架或写业务逻辑。
